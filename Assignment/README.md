# 📘 Assignment – Python Programming Tasks

This folder contains Python assignment programs divided into multiple sub-parts as per the academic assignment structure.  
The objective of these assignments is to build strong fundamentals in Python programming through consistent hands-on practice.

The assignments progressively cover arithmetic operations, string handling, conditional logic, loops, and functions.

---

## 📌 Assignment Structure

### 🔢 Assignment 1

#### 📄 Assignment 1.1 – Basic Mathematical Operations
- Takes two numbers as input from the user  
- Performs:
  - Addition  
  - Subtraction  
  - Multiplication  
  - Division  
  - Floor Division  
- Introduces arithmetic operators in Python  

#### 📄 Assignment 1.2 – String Concatenation
- Takes the user’s first name and last name as input  
- Concatenates both strings  
- Displays a welcome message  
- Demonstrates basic string handling  

---

### 🔍 Assignment 2

#### 📄 Assignment 2.1 – Even or Odd Number Check
- Takes a number as input from the user  
- Checks whether the number is even or odd  
- Uses conditional expressions  
- Introduces decision-making logic  

#### 📄 Assignment 2.2 – Print Numbers from 1 to 50
- Uses a `for` loop  
- Prints numbers from 1 to 50  
- Demonstrates loop control and iteration  

---

### 🔁 Assignment 3

#### 📄 Assignment 3.1 – Factorial Using Recursion
- Defines a function `factorial()`  
- Uses recursion with a base condition  
- Accepts user input  
- Displays formatted output  

#### 📄 Assignment 3.2 – Factorial Using Loop
- Defines a function `factorial()`  
- Uses a `for` loop to compute factorial  
- Demonstrates iterative logic  
- Accepts user input  
- Displays formatted output
